# Distributed asynchronous file processing system
This software tool is designed for asynchronous file processing using distributed computing resources and for providing users with processing results via a web interface. A file and the parameters for the required processing operation are fed into the system. The system is designed to perform operations such as conversion, compression, resizing, and other transformations on files of various formats. After the file is uploaded, a processing task is generated, which is placed in a queue and assigned to an available processor. The user can track the task’s execution status and, upon completion, view information about the result and download the processed file. The system must support the simultaneous processing of multiple tasks, load balancing among processors, monitoring the status of ongoing operations, and retrying tasks in the event of errors. The system is designed to store source and processed files, as well as information about created tasks and their execution results. React and TypeScript are planned for the client-side development, while Node.js and NestJS are planned for the server-side. To organize asynchronous execution and task distribution, we plan to use a message queue and separate worker processes. We plan to use Docker to containerize system components, PostgreSQL to store information about tasks and their status, and an object storage system to store source and processed files.
